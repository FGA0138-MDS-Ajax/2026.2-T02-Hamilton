# Sprints

O CoLecture é desenvolvido em **7 sprints de 7 dias**, cada uma com sua branch `sprintN`. Cada página de sprint registra os dados, o planejamento e os resultados, os requisitos implementados, a qualidade do software e a cobertura dos testes.

Clique no nome da sprint para abrir o relatório completo.

## Marcos de controle

- **11/11/2026, ponto de controle:** release com os requisitos R01 a R18, encerrando a Sprint 5.
- **16/11/2026, inspeção de qualidade:** os reparos são tratados na Sprint 7.

## Critérios de acompanhamento

- **Taxa de conclusão esperada por requisito:** 70%.
- **Atraso no cronograma:** taxa de conclusão inferior a 70% ao final da sprint leva à reavaliação do escopo das sprints seguintes.
- **Cobertura de testes mínima:** 100% dos requisitos planejados.
