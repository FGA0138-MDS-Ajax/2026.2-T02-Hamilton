# CoLecture

Plataforma web de leitura social, desenvolvida pelo **Grupo Hamilton** na disciplina Métodos de Desenvolvimento de Software (MDS), 2026.2, Universidade de Brasília (FCTE/FGA).

O CoLecture integra o acompanhamento individual da leitura ao engajamento comunitário: metas compartilhadas, ofensivas (dias consecutivos de leitura), fóruns por ciclo de leitura e recomendações por tema.
